# 🛡️ VKKVN Android Client — Releases

Официальный публичный репозиторий релизов и установочных файлов приложения **VKKVN** для Android.

## 📥 Скачать приложение

Актуальные версии всегда доступны в разделе **[Releases](https://github.com/sevastianovv/vkkvn-releases/releases)**.

| Архитектура | Файл | Описание |
| :--- | :--- | :--- |
| **ARM64 (v8a)** | `VKKVN-vX.X.X.XX-arm64-v8a.apk` | Для всех современных смартфонов (рекомендуется) |

### ⚡ Возможности VKKVN:
- Автономный TURN-туннель (vk-turn-proxy) с поддержкой протоколов обхода блокировок
- Встроенный оффлайн-сервер для быстрой локальной работы
- Независимая установка (пакет `com.vkkvn.app`) рядом с оригинальным клиентом
- Прямая интеграция с официальным Telegram-каналом `@vk_kvn`
- Автоматическая проверка и загрузка обновлений прямо из приложения
